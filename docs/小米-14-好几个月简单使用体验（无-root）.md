 - 140g 以下

## 初始配置
科学上网，小米应用商店安装 Play 商店后开始初始配置。

为了防止出现兼容性问题，这次换机没有用所谓的换机软件，软件都直接重装。个人安装的软件较多，200 +，从 Play 商店内容库里批量下载。未上架的开源软件在 github 或者 F-droid 装，其他的国产软件在小米应用商店，不安装间谍软件拼多多，微信小程序的功能已经足够正常购物了。

关闭了系统优化，关了系统自带的手势使用三大金刚。关闭系统优化的问题后面会提。

### 广告

广告主要分为系统级通知和第三方软件广告及推送，分开来说

#### 系统级广告
国产 UI 被诟病最多的地方，鉴于我使用的系统自带应用不多，除了小爱批量关广告之外，我只手动关了天气、钱包、应用商店的广告，浏览器没给通知权限，其他系统自带软件多数至今都没有打开。系统自带的安装器也是一个广告软件，不过我到手后就关了 MIUI 优化，只在安装 Clash 时见过一眼，忽略。
第二天又收到了「智能服务」伪装的京东广告，我用的原生通知样式，APP 图标暴露了，又去取消了智能服务相关的所有权限。
从此之后我就再也没有收到过系统级的广告推送了。

#### 应用内广告
个人很好奇网上一些用户只吐槽系统自带广告，绝大多数分分钟就能关掉，应用内广告显然比系统广告更碍事。

之前的 S20 因为 knox 的原因一直没有解锁，广告主要靠修改版 App，李跳跳和 Clash 规则来实现。就工具软件而言，Clash + 李跳跳比起有稳定更新规则源的 quanx 还是有差距，不过在开源的 Android 下配合修改版软件也算是够用。
这次从李跳跳换成了 [GKD](https://github.com/gkd-kit/gkd)，在线维护的点击规则也更适合我这种懒人。

接下来就是替换修改版应用。YouTube 换成了 YouTube Revanced，B 站 + bili 漫游，NGA 开源版，微博之前的两个第三方都还能用，小红书 + 猪手，知乎用 [Hydrogen](https://github.com/huajiqaq/Hydrogen) 等，都是基础操作就不多说了。

#### 应用广告推送

主要为涉及资金的软件，基本上也不能用第三方，没有什么很好的解决方法。

有通知需求的软件实际上也不是非常多，打开了权限收到应用方广告的情况下，只能在通知设置里依次开关通知类别权限，某些国产软件还是毒瘤，又想保留通知又要屏蔽广告推送只能和 iOS 一样跟厂家捉迷藏


### 系统设置

#### 系统优化（MIUI 优化）
即之前的 MIUI 优化，默认肯定是启动的，装好软件用了一天后发现如下问题

 - **FCM 推送锁屏后很快就收不到**，我用 FCM 接受通知的软件远比 Mipush 的多，影响很大

 - 最近任务界面不锁定的程序会自动清理后台，无法达到之前使用的手机两三天后点开后台即使重加载也还能恢复到同一个界面的程度

 - 软件包安装程序使用的是小米的安装器，会对安装软件进行审查（？）

 - 玩日系游戏迷之抽帧（提前说明：关掉了还是卡，只是略有缓解）



#### 默认应用
维持之前的配置原则，Google Calendar，Spark，Chrome，MX Player，Solid Explorer 等老牌软件依然能用，直接拿来替换掉小米自家的即可。

现在的小米系统不能直接修改默认启动器了，得安装新的第三方启动器后在第三方启动器内修改。放二次元壁纸还得是 Niagara Launcher。

另外全面屏时代的国产 UI 高度依赖官方启动器，使用第三方启动器会导致较多兼容性问题，包括且不仅限于：

 - 桌面壁纸变大
 - 最近任务界面程序不能长按会卡住
以上两点可以通过拉起一次 MIUI 启动器临时解决
 - 最近任务界面毛玻璃特效消失，相关过渡动画消失
 - 返回桌面时动画消失，如果关闭了系统优化则显示原生动画
 - 小窗模式下点击小窗程序全屏程序会返回桌面

### 关闭系统优化（MIUI 优化）

通常用户不推荐关闭，不过如果有海外软件和 FCM 推送、Split APK 安装等需求的情况下需关闭，请注意关闭后会产生一些**不可逆转的影响**，重新打开系统优化后仍然会出现兼容性问题

 - 默认字体发生变化，似乎无法改回默认的小米兰亭
 - 顶部状态栏图标部分变为原生样式，未适配软件直接显示一个大方框
 - 软件图标样式变化，在澎湃上未适配的变为直角，大部分出现问题的图标可以通过重新在主题内套用一次图标包解决（新版本的系统似乎解决了这个问题）
 - 软件 SplashScreen 重新出现
 - AOD 固定为无遮盖下常亮
 - 软件包安装程序变为 Android 原生
 - 部分软件刷新率适配失效（疑似随版本更新已修复？）
 - 部分海外游戏流畅度提升
 - Google 系列套件可用性提升
 - 高风险功能开启提醒无法关闭
 - 重启后输入法会被重置为搜狗小米定制版，需要手动启用其他输入法
 - 截屏工具被卸载，可在应用商店安装恢复
 - 应用详情（管理）变为 Android 原生，首次关闭系统优化时权限会被重置需要全部重新申请，自启动管理部分失效
 - 接上条，一部分软件重置后电池优化仍然会被自动改为受限，导致无法收到 FCM 推送，mipush 不受影响
 - 动画发生很大变化，大部分变为原生样式少部分过渡动画直接消失
 - 后台控制更偏向原生，杀后台变少，FCM 可用性提升
 - 内存拓展功能失效？16 + 1T 版本默认没有启用


## 问题
大部分是客观软件问题，少部分主观观点

### 相机畸变

主摄广角大光圈，提供了畸变校正的选项但是实测机内纠正仍然不足，在近距离拍摄屏幕、文件时更明显，目前看起来小米官方也完全没有进一步改善的意思

### 日系音游

プロセカ　デレステ　ミリシタ 等音游操作音和画面切换时**有延迟**，除了 pjsk 算是能玩以外其他两个游戏体验比较糟糕；
已经打开了所有游戏和延迟相关的选项，OneUI 也有此问题，莫非是定制 UI 的通病？

另外 3D 模式下，画面大幅度切换时会发生明显丢帧，期间会有几帧操作无响应；CGSS 经常出现加载卡住只能重开游戏的情况，不知道是个例还是通病

补充一下：**AR 模式不能使用，在小米应用商店安装了 AR 组件后也不能用，想要拍 AR 小偶像的请注意！！！**

### 没有最小化通知

原生和 OneUI 都有，保留通知的同时半高显示通知，澎湃却没有次选项

### 自由窗口（小窗）

旧版本关闭系统优化后可以通过开发者选项强制启用小窗 + 控制中心指令正常使用自由窗口，升级支持通知栏三图标的新版本 35/36 后小窗不能操作了

### 自动重置权限

上文已经提过，首次关闭系统优化时会发生，相当于更换了权限管理软件，可以理解

### 语音助手相关

小爱对中英混合等情况的识别较为糟糕，另外也不能像 Siri 和 Google Assistant 一样一句话唤醒 + 下发指令；默认语音助手固定小爱，虽然提供了选项但实质上无法替换

### 内存管理

 - 内存管理效率不如原生等，算上缓存占用，16 G 剩余小于 3G 就会出现卡顿，甚至是前台进程，合理的调度应该至少能保证干掉一些后台的情况下前台进程较流畅，而实际上后台除了锁上的，该杀的还是杀了，就有一种 iOS 的味道（仅指杀进程）

 - 对于没有特别优化的游戏（大概是王者原神之类的主流游戏？）前台调度较差，怀疑前台优先级不够；
