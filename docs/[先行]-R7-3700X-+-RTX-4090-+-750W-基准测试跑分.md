# 3DMark 基准测试

事先说明：显示器是双 4K @ 60 Hz，3Dmark 只运行在一个屏幕上，额外的屏幕会占用小比例的 GPU 性能。

2K 下瓶颈明显，Time Spy 跑分为 26xxx，远低于无瓶颈平台的 36xxx，实际 2K 性能在 7900XT 上下。

![Time Spy](https://hky.moe/img/230605.jpg#vwid=3840&vhei=2064)

4K 的 Time Spy Extreme 下分数就趋于正常了，Port Royal 虽然是基于 2K 的光追，不过似乎也是没有 CPU 瓶颈的，分数属于正常水平。

![Time Spy Extreme](https://hky.moe/img/230606.jpg#vwid=3840&vhei=2064)

![Port Royal](https://hky.moe/img/230607.jpg#vwid=3840&vhei=2064)

测试过程中，室温 24 ℃，机箱 P500A，观察到的最高温度为 72 ℃，大部分时间温度控制在 60 度以内。未修改显卡运行参数的情况下，显卡的最高功耗为 **452 W**，已经超出了 3 x 8pin 的理论供电能力，所以有条件的各位还是**建议插满**四口或直接用 16 pin。
