# 4090 低负载卡屏卡死

## 现象
4090 显卡在低负载如看视频或闲置情况下，画面忽然卡住不动，只能强制重启，高负载连续使用不会有此情况。

## 解决
一年多前可能有各式各样的方法，现在已经不需要了，尝试下面两种：

 - **更新 BIOS** 到最新，即便是老主板如 B450，在 2023 年底前应该都已经修复了该问题。

 - 如果主板更老已经不更新 BIOS 了，另一种不太好的方法：NVIDIA 控制面板中，将电源模式从普通模式调节为**高性能**模式


# AMD CPU 笔记本出现卡顿

## 现象
正常使用中忽然画面卡顿，鼠标移不动，声音卡带，几秒后恢复正常，不定期发生；**部分设备升级 BIOS 到最新版本仍然无效**。

## 问题
通常是 TPM 导致，升级主板 BIOS 后还是有此问题的可以考虑关闭 TPM。**关闭 TPM 后大概率不会再发生，也可能只能缓解不能根除**

[scode type="red"]请注意关掉 TPM 之前**确定设备已经关闭了 Bitlocker（家庭版开启了也不会直接显示，一定要注意）并且暂时删除 Windows Hello 验证**[/scode]

## 普通解决方法：BIOS 关闭 TPM

参考主板/笔记本厂商文档检查 BIOS 中有没有关闭 TPM 选项，关闭 TPM，大部分厂商放在 *高级 - 安全* 下。

关闭 TPM 后，重新添加回 Windows Hello 相关验证即可。

华硕等厂商笔记本可能未提供，参考下文。


## BIOS 没有 TPM？

通过在系统把 TPM 相关驱动替换成错误的驱动，让 TPM 停止运行，而后**禁用而不是卸载**设备
参考：[AMD平台打开TPM2.0后电脑偶尔会出现间歇性，持续时间极短的，如同电影慢动作一样的卡顿怎么办？ - 知乎](https://www.zhihu.com/question/490621460/answer/2245200111)

1. **确认所有 Windows Hello 验证方法（PIN，指纹识别，面部识别等）和 Bitlocker 已经关闭**
2. 设备管理器 - 安全设备 -找到 **受信任的平台模块** 或 **可信平台模块**
3. 右键属性 - 驱动程序 - 更新驱动程序 - 浏览我的电脑以查找驱动程序 - 让我从计算机上的可用驱动程序中获取
4. 取消勾选「显示兼容硬件」，选择 Advanced Micro Devices Inc.（AMD），随便选择一个 PSP Device 安装
5. 再看一遍步骤1，重启
6. 重启后，在设备管理器里确认 AMD PSP Device 属性中是否已经不能正常工作
7. 恢复 Windows Hello 相关验证


## 我的使用效果
关闭 TPM 后，仍然还是有卡顿，目前还是没有定位到真实原因，不过出现卡顿的频率有所下降，并且卡顿的时间从之前的约 1 秒下降到了小于 0.4 秒，对我的办公使用已经基本无影响。又不是不能用（
