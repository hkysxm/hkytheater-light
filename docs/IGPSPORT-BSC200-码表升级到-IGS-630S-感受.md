# 升级原因
 - BSC200 只有轨迹导航功能，三岔路口导航容易走错的同时距离路线直线 200m 以上才会提示偏航
 - 单色屏幕，按了暂停再看导航有可能会忘记按继续
 - 通知只显示标题，不显示内容
 - 没有光线感应，白天进没灯隧道看不清

# 升级体验
 - 续航很长，同情况下大于 BSC200
 - 推车下楼搜星速度更快，高架下树荫下掉速改善
 - 彩色屏幕再也不会导航忘记取消暂停
 - 导航地图缩放速度更快
 - 各界面均能**多显示一行**很实用
 - 通知有标题和内容，虽然长消息显示不全
 - 有**电子罗盘**和**光线感应器**
 - 上海没坡，爬坡规划没法测
 - 天气预报有**风向**提示不错
 - 自动导航到**保存点路线不一定准确**，请注意
 - 坡度仍然基于 GPS + 气压，延迟老样子

# 总结
骑游为主可以升级，导航功能的增强和爬坡规划让探索新路线和走长途更方便了。
因此 BSC300 用户不是非常有必要升级。
需要进阶训练数据的推荐直接佳明。
